# 🎵 Brisa & Ritmo

Widget personalizado para la pantalla LCD del **Corsair Vanguard Pro 96**, desarrollado para funcionar dentro de **Corsair iCUE**.

El proyecto combina información del clima con la reproducción multimedia actual en una interfaz diseñada específicamente para la pantalla integrada del teclado.

## ✨ Funcionalidades

- 🕐 Hora actual
- 🌤️ Clima y temperatura
- 📍 Ubicación configurada
- 🎵 Canción y artista en reproducción
- 🖼️ Fondo personalizado
- ⚙️ Configuración desde iCUE

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- Fetch API
- JSON
- Corsair iCUE

## 💡 Sobre el proyecto

Este fue uno de mis primeros proyectos trabajando con **HTML, CSS, JavaScript y APIs**.

Nació como una forma de aprovechar mejor la pantalla de mi teclado y terminó siendo una muy buena oportunidad para aprender sobre consumo de APIs, manejo de datos, diseño de interfaces para pantallas pequeñas e integración con hardware.

El proyecto también me permitió enfrentar distintos problemas durante el desarrollo, investigar soluciones y llevar una idea propia desde las primeras pruebas hasta verla funcionando en un dispositivo físico.

## 🚀 Estado

El widget se encuentra funcional y puede seguir recibiendo mejoras y nuevas funcionalidades.
